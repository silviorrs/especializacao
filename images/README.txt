Pasta de Imagens - Site IAGA UTFPR Londrina
=============================================

As imagens oficiais do Câmpus Londrina da UTFPR devem ser
baixadas do álbum oficial do Flickr:

https://www.flickr.com/photos/utfpr/albums/72157703155262791/

Imagens recomendadas para o site:
- campus-londrina.jpg (foto principal do campus para o hero)
- campus-londrina-2.jpg (foto secundária para seção sobre)
- utfpr-logo.png (logotipo oficial da UTFPR)

Coloque os arquivos baixados nesta pasta e referencie-os
no HTML conforme necessário.

Exemplo de uso no HTML:
<img src="images/campus-londrina.jpg" alt="Campus Londrina UTFPR">
